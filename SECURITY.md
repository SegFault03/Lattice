# Security reporting

Use GitHub's **Report a vulnerability** private-reporting option when enabled for this repository. Maintainers should enable private vulnerability reporting before the public release.

If that option is unavailable, open an issue requesting a private reporting channel without including exploit details or sensitive data. Do not post passwords, full production JDBC URLs, tokens, customer records or unredacted IDE logs publicly.

Include affected Lattice/IDE/database/driver versions, a minimal synthetic reproduction and the potential impact. The current release receives fixes; older releases may require upgrading. No response-time guarantee is made.
