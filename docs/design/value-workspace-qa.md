# Cell inspector: native review

The inspector now names the selected column in its heading. A selected cell shows its one-based row and column numbers underneath; a header selection shows its column number and Structure. The table name stays in a smaller line above the title.

The layout uses a 24 px content inset, consistent 8/16 px spacing, 34 px header controls with 18 px vector icons, and equally tall primary actions. Tabs, the value canvas, actions, metadata, and footer share a left edge. The editor adapts to the available height so the bottom dock does not obscure metadata; actions wrap in a narrow panel. The pin changes from a tilted outline to an upright, filled blue icon with an active surface. Both header controls have hover and keyboard focus states and accessible names. Metadata uses explicit muted colors rather than the IDE's much dimmer info-label substitution; the designed foreground/background contrast is 4.65:1 in Light and 7.14:1 in Dark.

These full 1920 × 1080 images were captured during this review in IntelliJ IDEA Ultimate 2026.2.3 (build 262.10968.63). The [before capture](cell-inspector-before-dark.png) documents the generic title, tiny header controls, inconsistent action insets, and cramped footer that prompted this revision.

1. **Cell selection — checked.** The [Dark inspector](value-workspace-idea-dark.png) and [Light inspector](value-workspace-idea-light.png) show `email`, `Row 1 · Column 4`, the full Edit value label, and all three column metadata rows. The large value canvas keeps the selected value prominent. Wrap uses text color for state without a background.
2. **Column inspection — checked.** The [Dark column view](column-workspace-idea-dark.png) and [Light column view](column-workspace-idea-light.png) keep the same heading and spacing, followed by the SQL type card, definition, and constraints. The duplicated Name row and doubled divider are removed.
3. **Actions — checked.** The [pinned cell](value-workspace-idea-pinned-dark.png) and [pinned column](column-workspace-idea-header-pinned-dark.png) retain their original target after another cell is selected. Double-clicking the value enters [inline editing](value-workspace-idea-editing-dark.png). Cancel exits editing; the [close control](value-workspace-idea-close-hover-dark.png) removes the panel, and selecting a cell reopens it.
4. **Theme changes — checked.** The native run switches Dark → Light → Dark while the panel is open. The [restored Dark view](value-workspace-idea-restored-dark.png) and Light captures were inspected for stale surfaces, clipped text, and alignment changes.

An intermediate native capture caught two issues that the approximate preview did not: a truncated primary action in Dark and metadata clipped by the dock after the taller heading was introduced. Explicit action sizing and an editor that fits the available height address both. The Java suite passes 194 tests, and the native flow checks cell/header pin persistence, double-click editing, close/reopen, and theme changes. [Runtime evidence](value-workspace-native-evidence.txt) is saved beside the captures.

The screenshots establish appearance at 1920 × 1080 and the native flow establishes the interactions above. They do not establish every UI scale, high-contrast theme, keyboard path, or screen-reader behavior. Focus outlines and accessible control names are implemented; full accessibility testing remains separate.
